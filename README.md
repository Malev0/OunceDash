# OunceDash

A Nintendo Switch 2 homebrew that runs **your own copy** of Geometry Dash
for Android natively: native resolution, up to 120 fps, controller support,
touch, online level and song search.

OunceDash is only a loader. It contains no game code or assets. The game's
libraries and assets are read at runtime from the APK you put on the SD
card, so you need to own the game. Built with the
[ouncebrew](https://github.com/ouncebrew) tools (kaiHEN, libounce, OunceVK).

Tested with Geometry Dash **2.2.145** (Android, arm64). See
[Other game versions](port/README.md#other-game-versions) for newer builds.

---

## Setting it up on the console

You need a Switch 2 running **kaiHEN** (OunceDash needs kaiHEN's `ldr:ro`
to map the game's code) and hbmenu.

1. Build `OunceDash.nro` (see below), or take it from a release.
2. Create `sdmc:/switch/OunceDash/` on the SD card and copy into it:
   - `OunceDash.nro`
   - your Geometry Dash APK (any file name ending in `.apk`). It must
     contain `lib/arm64-v8a/`.
3. *Optional, recommended:* if you also own the PC version, copy its
   `Resources` folder to `sdmc:/switch/OunceDash/Resources/`. OunceDash
   then uses its sharp `-uhd` textures (with Texture Quality set to Medium
   or High). The APK only has `-hd` textures, which look soft at 1080p and
   above.
4. *Optional:* to bring an Android save over, copy `CCGameManager.dat` and
   `CCLocalLevels.dat` into `sdmc:/switch/OunceDash/save/`.
5. Start a game holding **R** to get hbmenu (kaiHEN), then open
   **OunceDash**.

The first launch creates:

```
sdmc:/switch/OunceDash/
    config.ini     settings: max_fps, render size, VRR, cursor, quit action...
    controls.ini   button mapping (every option is listed in the file)
    save/          game saves, downloaded songs and SFX
    log.txt        loader log: check this first if something goes wrong
    cache/         sharp icon files packed into one file (built on the first
                   launch with Resources, with a progress screen; delete it
                   to rebuild)
```

### Controls (defaults)

| Switch | In a level | In menus |
| --- | --- | --- |
| A, R, ZR | Jump | A / ZR: click at the cursor |
| L, ZL | Player 2 jump (also jumps in normal levels) | — |
| B | Controller B | Back |
| + | Pause | — |
| − | Toggle the FPS counter | Toggle the FPS counter |
| D-pad / left stick | Platformer movement | D-pad: navigate; stick: cursor |
| Right stick | Player 2 movement (2-player on one controller) | Cursor |
| Second controller | Player 2 (A/R/ZR jump, D-pad/stick move) | — |
| Touchscreen | Works everywhere | |

These follow the game's own default controller keybinds (jump is
Controller A and RB). Change the game's keybinds or `controls.ini` to
rearrange them.

Remap anything in `controls.ini`. All settings are described in
[port/README.md](port/README.md#configini).

### Performance

Menus and most levels run at 120 fps. Very demanding levels can drop
below that: GD's own per-object work in those levels needs more CPU time
per frame than Switch 2's ~1.1 GHz CPU allows. The loader keeps its own
overhead small (dedicated cores, icon cache, rotating vertex buffers); see
[Status](port/README.md#status) for the measurements. Press **−** to show
the frame rate.

## Building

OunceDash builds with devkitPro plus the ouncebrew Switch 2 packages.

### 1. Install devkitPro

Install devkitPro's pacman: <https://devkitpro.org/wiki/Getting_Started>.
On Windows, use the devkitPro installer and run the commands below in its
**MSYS2** shell (`C:\devkitPro\msys2\msys2_shell.bat`). Drop `sudo` and use
`pacman` instead of `dkp-pacman` there.

### 2. Add the ouncebrew package repository

Import the signing key:

```bash
curl -fsSLO https://pkg.ouncebrew.org/ounce.gpg
sudo dkp-pacman-key --add ounce.gpg
sudo dkp-pacman-key --lsign-key DFEAE7FA965D1E6C0D41D4D75DB9FDBFA4A4DE29
```

Add the repository to `pacman.conf` (`/opt/devkitpro/pacman/etc/pacman.conf`,
or `C:\devkitPro\msys2\etc\pacman.conf` on Windows):

```ini
[ounce]
Server = https://pkg.ouncebrew.org
```

### 3. Install the packages

```bash
sudo dkp-pacman -Syu
sudo dkp-pacman -S devkitA64 libounce ouncevk libkaihen switch-mesa switch-zlib
```

Keep them current with `sudo dkp-pacman -Syu` (it was last built against
the 2026-11-17 packages).

### 4. Build

```bash
export DEVKITPRO=/opt/devkitpro
cd port
make
```

That produces `port/OunceDash.nro`. `make clean` removes the build output.

The hbmenu icon (`port/OunceDash.jpg`) is generated by
`python port/tools/make_icon.py port/OunceDash.jpg` (needs Pillow). It is
committed, so you only need this to change it.

## Repository layout

```
port/
    Makefile          build (libounce switch2_rules)
    OunceDash.jpg     hbmenu icon
    README.md         technical details: how the loader works, config keys,
                      controls, version support, source map
    source/           the loader
    third_party/      jni.h (Apache-2.0, AOSP), stb_truetype.h (public domain)
    tools/            development helpers
```

Not in the repository, by design: the APK, the extracted APK, the PC game
files, saves, and build output (see `.gitignore`).
